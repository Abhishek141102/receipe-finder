# 🍲 Recipe Finder

A simple and fast recipe search app built with **React + Vite**. Search for any recipe, get a random recipe suggestion, view detailed cooking instructions, and save your favorite recipes — all powered by [TheMealDB API](https://www.themealdb.com/api.php).

## ✨ Features

- 🔍 Search recipes by name
- 🎲 Get a random recipe suggestion
- 📖 View detailed recipe info (ingredients, instructions, etc.)
- ❤️ Save recipes to your Favorites list
- ⚡ Built with Vite for a fast dev experience

## 🛠️ Tech Stack

- React.js
- Vite
- React Router DOM
- Axios
- React Icons
- TheMealDB API

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/<your-username>/receipe-finder.git
   cd receipe-finder
   ```

2. Install dependencies
   ```bash
   npm install
   ```

3. Start the development server
   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser
